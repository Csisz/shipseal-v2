# ShipSeal AI Development Tooling

## Codex MCP servers

- Playwright MCP
  Purpose: rendered UI testing, browser interaction, responsive QA

- shadcn MCP
  Purpose: component discovery and UI implementation

- Figma MCP
  Purpose: design context and design ↔ code workflows

## Repository skills

- motion
  Purpose: React/SVG motion and interaction implementation

- shadcn
  Purpose: correct use of the ShipSeal shadcn setup

- shipseal-motion-ui
  Purpose: ShipSeal-specific visual language, motion rules,
  neural/repository visualization principles and visual QA workflow

## Usage policy

For significant ShipSeal UI work:

1. preserve the current product specification and sprint scope;
2. use Motion for meaningful animation where appropriate;
3. use shadcn for conventional UI components where appropriate;
4. use Playwright to inspect the actual rendered result;
5. use Figma only when design context genuinely helps;
6. follow the shipseal-motion-ui skill for ShipSeal-specific visual behavior.

Important:
The MCP servers listed above describe the local Codex development environment.
Their presence in this project document does not mean that the same MCP
server is connected to ChatGPT Online.
