## Deferred commercial and platform scope

Payment/entitlements, public sharing/badges, teams/organizations, scheduled or webhook rescans, automatic merge, direct default-branch writes, cross-repository Futures, several simultaneous final plans, command execution, numeric ROI/effort/token/time/success predictions, autonomous provider selection and automatic cleanup of partial GitHub branches remain deferred.

## Release gates

Repository Futures ships only when:

- deterministic evidence remains authoritative and provider output remains bounded untrusted enrichment;
- one primary, at most two supports and complete required closure are enforced in domain and UI;
- current Universe truth never becomes a copied Future graph;
- Prepared, Exported, Applied to review branch, PR opened, Pending verification and verification outcomes remain distinct;
- ZIP/manual and GitHub derive from one immutable prepared snapshot;
- GitHub writes stay explicit, branch-only, server-authorized and recoverable;
- verification requires compatible owner/project/repository/branch/scanner/measurement/plan/evidence identity;
- unresolved, incompatible or regressed relationships cannot unlock a Future;
- the complete workflow works without WebGL, hover, motion, color or a mouse;
- gzip, interaction, NodeNext, browser-marker, secret, migration, test, lint, build and human-review gates pass;
- Delivery Pack, Client Handoff, reports, manifests and `score.json` remain truthful compatibility outputs;
- applicable client-facing compliance material retains **This is not legal advice.**
